# 문서

| 파일 | 대상 | 내용 |
|---|---|---|
| `주간결-인수인계-문서.pdf` | 프로젝트를 넘겨받는 사람 | 무엇을 만들었고, 왜 그렇게 만들었으며, 지금 무엇이 위험한가 |
| `주간결-코드-안내서.pdf` | 코드를 처음 보는 개발자 | 코드 구조, 개념 설명, 직접 고쳐보는 실습, 함정과 오류 사전 |

PDF의 원본은 같은 폴더의 `handover.html`, `guide.html`이고
공통 스타일은 `doc-style.css`입니다. **PDF를 직접 편집하지 말고 HTML을 고친 뒤
다시 생성하십시오.**

## 다시 생성하기

```bash
npm install -D playwright
npx playwright install chromium
node docs/make-pdf.mjs
npm uninstall playwright        # 평소에는 의존성으로 두지 않습니다
```

A4, 한글 본문은 맑은 고딕 계열을 사용합니다. 다른 OS에서 생성하면 글꼴이
달라져 줄바꿈 위치가 바뀔 수 있습니다.

## 갱신 원칙

코드를 바꾸면 문서도 함께 갱신하십시오. 특히 다음 두 곳은 사실과 어긋나는 순간
문서 전체의 신뢰가 사라집니다.

- 인수인계 문서 **3장 핵심 설계 결정**
- 인수인계 문서 **7장 알려진 한계와 리스크**

코드와 다른 설명은 없는 것보다 나쁩니다.
